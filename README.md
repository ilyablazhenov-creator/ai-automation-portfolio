# Витрина автоматизаций

Короткая интерактивная страница: задаёте задачу своими словами — получаете ответ, есть ли в каталоге
такая автоматизация, и краткое описание того, что это.

**Открыть:** файл `index.html` двойным щелчком или страница на GitHub Pages. Страница самодостаточна:
один файл, без внешних запросов, работает без интернета.

## Что внутри

- Каталог из 171 автоматизаций в 13 областях: производство и качество, финансы и отчётность, документы,
  ИТ-эксплуатация, ИИ-помощники, обучение и допуск, оргпроцессы.
- Вопрос вводится в свободной форме. Ответ — одно из трёх: **есть**, **есть близкое**, **нет**.
- К ответу прилагается краткое описание: что это и для кого. Ссылку на конкретный вопрос можно переслать:
  адрес вида `…/index.html#q=учёт отпусков`.

## Чего здесь нет — намеренно

Устройства решений, технологического стека и расчётов эффекта. Каталог демонстрирует, **что** автоматизировано;
как именно и с каким результатом — предмет личной беседы.

## Обезличивание

Описания подготовлены из внутренних проектов и очищены от названий организаций, продуктов, людей, адресов
и любых внутренних идентификаторов. Проверка выполняется автоматически при каждой сборке.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки.
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту страница будет доступна по адресу вида `<имя>.github.io/<репозиторий>`.

Файл `.nojekyll` отключает обработку Jekyll, чтобы страница отдавалась как есть.
